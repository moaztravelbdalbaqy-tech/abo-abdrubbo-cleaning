# موقع أبو عبدربه لخدمات التنظيف

موقع عربي متجاوب (RTL) مبني باستخدام HTML وCSS وJavaScript بدون أطر عمل.

## الملفات
- `index.html` الصفحة الرئيسية ومحتوى الخدمات والأسعار والتواصل.
- `style.css` تصميم متجاوب بألوان الكحلي والذهبي.
- `script.js` قائمة الهاتف والسنة الحالية.
- `assets/` الصور الإعلانية التي أرفقتها.

## التشغيل
افتح `index.html` في المتصفح لمعاينة الموقع. لا يحتاج إلى تثبيت.

## النشر
ارفع جميع الملفات والمجلدات كما هي إلى استضافة تدعم المواقع الثابتة، مثل GitHub Pages أو Netlify أو cPanel. لا ترفع `index.html` وحده؛ يجب رفع `style.css` و`script.js` ومجلد `assets` أيضًا.

## قبل النشر النهائي
- تأكد من رقم واتساب/الهاتف والبريد الإلكتروني.
- راجع أسعار العروض ومدى سريانها.
- أضف روابط صفحات Instagram وFacebook الرسمية عند توفرها.
- تأكد من مناطق الخدمة والعنوان الدقيق.
